# Aple Motion Timing Implementation Plan

> For agentic workers: execute task-by-task; verify every completion claim against current test/build output.

Goal: deliver the temporal foundation and mobile inspector for an additive Aple Motion integration.

Architecture: immutable validated timing models, exact tick/frame planning, and a required transactional host adapter. Preserve all existing compiled app files.

Tech Stack: Swift 5.9+, Foundation, UIKit, XCTest, macOS GitHub Actions and the iOS SDK.

Spec: `docs/superpowers/specs/2026-10-14-effectcraft-mobile-design.md`.

Global constraints: iOS 15+, no private ABI guesses, no replacement editor, no font binaries, no signing secrets, no false IPA or full-parity claim.

Review focus: full-influence midpoint, equal-valued keys with nonzero speeds, rational rates and terminal PTS, reverse/freeze bounds, invalid or future serialized documents.

## 1. Core contracts

Create `Package.swift` and `Tests/ApleTimingCoreTests/TimingTests.swift`. Tests must cover linear interpolation; incoming Hold and outgoing Hold; one-sided Bezier; equal endpoints; full-influence midpoint; negative speed; exact Bezier integral versus numerical quadrature; frame-count half-open interval; invalid inputs; Codable validation. Record the initial failing run, implement in `Sources/ApleTimingCore/Time.swift`, `TemporalCurve.swift`, and `TimingDocument.swift`, then verify `swift test` passes.

## 2. Mobile inspector

Create `Sources/ApleTimingUI/TimingEditor.swift`. Consume `TimingDocument`, `ScalarCurve`, `SpeedRamp` and `Tick`. Provide `LayerTimingSnapshot`, `TimingHostAdapter` and `TimingEditorViewController`. Host preview is temporary, Cancel rolls it back, and Apply requires the original snapshot revision. Numeric fields remain an accessible alternative to touch graph manipulation. Compile for iOS device and simulator; do not confuse compilation with device UI testing.

## 3. Parity and packaging

Create `scripts/upstream-parity.py` to compare the Swift scalar easing evaluator with the actual pinned upstream Rust solver, retaining upstream copyright/license. Create `scripts/build-framework.sh` to build device and simulator XCFrameworks without signing or replacing the original application. Publish test logs and frameworks through `.github/workflows/timing.yml`. Never publish the user's original app binary or secrets to this public repository.

## 4. Integration gate

Obtain verified v4.34.38 host source or a documented, tested project-mutation bridge. Connect real layer snapshots, preview, commit, undo, persistence and export. Validate existing projects and render regressions, then package and test an IPA. This task is blocked until those inputs and a functioning archive-processing path exist; the earlier tasks must still be delivered honestly.
